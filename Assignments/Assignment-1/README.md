# Assignment 1: Intensity Transformations and Neighborhood Filtering

EN3160 – Image Processing and Machine Vision

This folder contains the Jupyter Notebook and images for Assignment 1.

## Topics
- Intensity transformations and gamma correction
- Vibrance enhancement

- GrabCut segmentation and background blurring
- Bilateral filtering

## Tools
Python, Jupyter Notebook, NumPy, Matplotlib, and OpenCV.
