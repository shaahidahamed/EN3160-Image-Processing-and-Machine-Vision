# Assignment 2: Fitting and Alignment

EN3160 – Image Processing and Machine Vision

This folder contains the Jupyter Notebook and images for Assignment 2.

## Topics
- Blob detection using Laplacian of Gaussian and scale-space extrema
- Line and circle fitting using RANSAC
- Homography estimation and image warping
- Image superimposition and blending
- SIFT feature detection and matching
- PCB image alignment and difference analysis

## Tools
Python, Jupyter Notebook, NumPy, SciPy, Matplotlib, and OpenCV.
